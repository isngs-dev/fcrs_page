# Sprint A6 — Calling Agent, outbound (Plivo, turn-based)

> **Status:** IMPLEMENTED (awaiting review) · spec v1 · 2026-10-16 — see **As built** at the end
> **Parent docs:** [`../calling_agent.md`](../calling_agent.md) · [`../adr/ADR-002-voice-pipeline.md`](../adr/ADR-002-voice-pipeline.md)
> (P1 turn-based XML) · [`../compliance.md`](../compliance.md) §2/§5 · [`A1.md`](A1.md) (gate, dispatcher, executors)
> **Outcome:** a claimed `call` task dials the contact from the tenant's Plivo number. The first sentence
> discloses the AI and the recording; recording starts only after it and stops + is deleted on objection.
> Rebecca answers from the knowledge base, offers two open slots and books on an explicit "yes", handles
> "stop", "call me later", wrong numbers, voicemail and silence, and hands off to a person when needed.
> Every call leaves a session, a transcript with per-turn latency, an outcome, a summary, a cost row and
> a CRM activity. Calls only ever reach contacts that pass the A1 gate (call consent, window, limits).

## Decisions

| # | Decision | Why |
|---|---|---|
| L1 | **Per-tenant config, no platform default** (`tenant_call_agent_configs`): Plivo auth id + auth token (AES-GCM, AAD = tenant), `from_number` (E.164, the bought number), `transfer_number`, `company_name`, TTS `voice`, optional `voice_model`, `voicemail_policy` (`hangup` \| `leave_message`) + `voicemail_message`, `max_call_seconds` (default 300), `max_concurrent_calls` (default 2), `recording_enabled` (default on). The same Plivo account can be pasted for every tenant | Brief / PHASE0 C2 |
| L2 | `TelephonyProvider` Protocol + `PlivoTelephony` (raw httpx like `voice_agent/plivo.py`): `place_call` (async AMD on), `start_recording`, `stop_recording`, `delete_recording`, `transfer_to_url` | calling_agent §1; ADR-002 P1 |
| L3 | **Webhooks** `/public/call-agent/calls/{call_id}/{answer\|turn\|machine\|voicemail\|dial-status\|hangup}?ticket=…`: the HMAC ticket (purpose `call-agent`) proves the call is ours, then `X-Plivo-Signature-V3` is checked with **that tenant's** auth token. Any failure → the same 401 | Reuses `voice_agent` verification |
| L4 | **Script order is code-owned:** first `<Speak>` = "Hi{, first name}, this is Rebecca, an AI assistant calling on behalf of {company}. This call is recorded for quality." + purpose + "Is now a good time?". Recording starts on the **first turn webhook** (the disclosure has been heard), never before. "Don't record" → stop + delete, `recording_consent=false`, call continues | calling_agent §3; compliance §5 |
| L5 | **Turn rules (pure, `call_agent/script.py`)**, checked before any LLM: opt-out ("don't call", "remove me", "stop calling") → suppress `call`, `opt_out_received`, goodbye; wrong number → suppress the number, goodbye; "call me later/busy/not now" → callback (task rescheduled to the next day's window), goodbye; recording objection; "are you a robot/AI?" → "Yes, I'm an AI assistant…"; asks for a person → transfer (if a transfer number is set) else callback by the team; wants to book → offer slots; goodbye; silence (twice → goodbye). Otherwise → grounded answer (`voice_agent.answer_from_knowledge`, `voice_model` if set); no answer → offer the team callback | calling_agent §4 |
| L6 | **Booking on the call:** two next open native slots (≥ 2 h ahead, within 7 days) are read back with day, time and timezone; the caller picks one ("the first", "Tuesday", "3 PM"); Rebecca reads it back and books only on an explicit yes → `schedule_events` + reminders + confirmation email (existing notification path) + `meeting_booked`. Tenants whose calendar lives in Google/Calendly get "I'll email you a link" instead (team hand-off). **Changed 2026-10-28:** the caller names the day and time (nearest open times offered when it's taken), confirms or says the email the details go to, then it's booked; a connected Google calendar now books natively + syncs a Meet link (only Calendly hands off) — see calling_agent §3 | calling_agent §3.5; no double-booking |
| L7 | **Voicemail:** async AMD (`Machine=true`) → Plivo Transfer API to our `voicemail` XML → hang up, or speak the approved message (must contain "AI", the company and the callback number — validated on save) → outcome `voicemail`. **Superseded 2026-10-27:** the verdict is only noted; the voicemail branch runs when nobody answers the opening (see calling_agent §4) | calling_agent §4 |
| L8 | **Task lifecycle:** the executor places the call and parks the task in `pending`; the hangup webhook settles it: answered → `completed` (a touch); no answer / busy / voicemail / failed → rescheduled (+1 day, window-adjusted by the gate) while attempts < `max_attempts`, else `failed`; callback → rescheduled without counting a touch. A session stuck in `dialing`/`in_progress` past `max_call_seconds + 10 min` is reaped as failed | A1 dispatcher semantics |
| L9 | **Concurrency** is a gate check (`CALL_CONCURRENCY_LIMIT`, retry in 5 min, no attempt consumed) via a per-channel capacity hook registered by the call agent | compliance §1 order 7 |
| L10 | **Hard limits:** Plivo `time_limit = max_call_seconds`; Rebecca wraps up on the first turn past `max_call_seconds − 30 s` | calling_agent §5 |
| L11 | **After the call** (outbox `call_completed`, enabled now): LLM summary + sentiment from the transcript, CRM activity on the contact's lead, `usage_costs` row (`telephony`, minutes × `CALL_COST_MICROS_PER_MINUTE`, default 0), and stop the plan on `not_interested`/`wrong_number`/`opted_out` | calling_agent §6 |
| L12 | **Latency is measured, not guessed:** each Rebecca turn stores `latency_ms` (webhook received → XML returned); `GET /admin/outreach/calls/latency` gives p50/p95 for the A6b decision | ADR-002 decision 2 |
| L13 | English only, US only (inherited). Inbound calls and warm-transfer whisper are A7 | PHASE0 |

## API
Admin (`/admin/outreach`, CLIENT_ADMIN writes, CLIENT_AGENT reads): `GET/PUT /call-config`,
`GET /calls?status=`, `GET /calls/{id}` (with transcript), `GET /calls/latency`. Public: the Plivo
webhooks (L3). `PUT /settings` enabling `call` requires a ready call config (`CALL_NOT_READY`).

## Tests
Unit: script rules table (opt-out, wrong number, callback, robot question, person, booking, recording
objection, goodbye), disclosure is the first spoken text, slot phrasing + choice matching, voicemail
message validation, ticket tamper. Integration (real DB, Plivo faked with httpx MockTransport):
dispatcher → call placed with AMD + signed URLs; answer XML starts with the disclosure; first turn starts
recording; objection stops + deletes it; "don't call me" suppresses + stops the plan before hangup;
booking flow books the chosen slot and sends the confirmation; voicemail path; no-answer reschedules
until attempts run out; hangup settles the task and emits `call_completed`; bad signature/ticket → 401;
tenant B's ticket can't drive tenant A's call; concurrency limit defers; RBAC on admin routes.

## As built (2026-10-16)

| # | Note |
|---|---|
| M1 | "Yes"/"no" only count for short replies (≤ 4 words, no question mark): "Sure, how much is a repair?" is answered as a question |
| M2 | "Not interested / no thanks / we already have one" is its own rule → polite close, outcome `not_interested`, plan stopped after the call |
| M3 | A goodbye after a booking keeps the outcome `booked`; the booking itself emits `meeting_booked` with the call's contact id (no email lookup, so phone-only contacts stop their plan too) |
| M4 | A booking made on the call sends the standard booking-confirmation email (existing notification path) and creates the 3 reminders; tenants on Google/Calendly get "the team will send you a link" (hand-off), never a native booking |
| M5 | A recording objection stops and deletes the recording and the call never re-starts it; the recording URL is cleared after the call when consent was withdrawn |
| M6 | Hand-offs (asked for a person without a transfer number, two unanswered questions, time limit, LLM error) write an `agent_call_needs_human` feed event |
| M7 | Not built here: inbound calls, warm-transfer whisper, call-me-at-a-specific-time parsing (callback = next day, window-adjusted), barge-in measurement on a real line — A7 / A6b |
